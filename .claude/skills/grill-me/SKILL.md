# Grill Me

Walk through the design's decision tree one meaningful question at a time.
Recommend an answer for each question and explain the tradeoff briefly. Read
the repository or issue first when it can answer the question. Continue until
the goal, interfaces, edge cases, verification, and ticket boundaries are clear.

Use the interactive question tool when available. Do not ask the user to
decide facts that can be established from the codebase or GitHub issue.
